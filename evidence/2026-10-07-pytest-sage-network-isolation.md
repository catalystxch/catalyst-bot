# Isolate the ordinary pytest suite from the operator's Sage wallet

During the exact `221399a` serial Windows backend run, the pytest process had two established connections to the real Sage RPC port `127.0.0.1:9257`. The test suite was stopped without treating it as an acceptance pass. A direct read-only Sage snapshot after the interruption showed the expected TEST 7 fingerprint and MZ asset, unchanged XCH and MZ balances, zero pending transactions, and zero nonterminal offers. The specific test that opened those connections was not established.

The suite already used a temporary `CMM_DATA_DIR`, but its config still defaulted to the operator's Sage RPC and could discover the operator's TLS files. The session fixture now sets a closed local RPC endpoint and nonexistent TLS paths under the temporary data directory before CATalyst imports. It seeds the same values into that directory's `.env`, so a normal config reload cannot restore the live defaults. Function and module fixture teardown restore safe process defaults after tests that exercise synthetic Sage settings. A caller-supplied existing `.env` with different Sage connection settings fails test collection; a probe with `SAGE_RPC_URL=https://127.0.0.1:9257` exited with code 4 before tests ran. Subprocess tests retain their own synthetic `.env` behavior.

The new regression was red before the fixture change. The isolation and subprocess startup tests passed after the correction (**4 passed**); the combined wallet/config and certificate subset passed (**149 tests, 22 subtests**); the complete mutation-gate file passed (**265 tests**). Ruff and format checks passed. A first full run using a process-env override was intentionally stopped after a subprocess test-order failure; that approach was removed. A second full run found an expected `ssl/wallet.crt` path-shape requirement; the safe fixture path was corrected without using a real certificate. The final full serial Windows backend suite passed **7,353 tests, 246 skipped, 447 subtests** in 1,180.49 seconds. Its stdout receipt is `E:\catalyst-pytest-wallet-isolation-full-v3.stdout.log` (SHA-256 `23AAA6B9816E94872B83924AA9B07FDD5364740912A06724AE0ADB881193DE9B`); stderr was empty. Concurrent read-only socket monitors recorded **667 parent-process samples and 386 all-Python samples, zero connections to the live Sage RPC port 9257**. Exact-source clean-package verification and final PR checks remain pending.

This is test-harness isolation. Runtime/source `221399a` remains unchanged, and none of these checks completes original-profile live acceptance or either 24-hour release window. PR #220 stays draft.
