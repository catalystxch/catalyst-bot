# Local Sage Full-App Acceptance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce and verify a local Windows CATalyst build that exercises every primary operator workflow against the authorised Sage TEST 7 wallet, with bounded live effects and a clean final reconciliation.

**Architecture:** Run the committed PyInstaller onedir build from the isolated `codex/stability-kernel` worktree with `CMM_DATA_DIR` set to the isolated TEST 7 lab. Verify the complete path from native PyWebView and browser UI through Flask endpoints, the SQLite state layer, and Sage RPC; keep the first pass non-posting, then use a tightly bounded live lifecycle and reconcile all resulting wallet and offer state.

**Tech Stack:** Python 3, PyInstaller, Flask/SSE, PyWebView, vanilla HTML/CSS/JavaScript, SQLite WAL, Sage wallet RPC, pytest, agent-browser, Windows Computer Use.

**Spec:** `docs/superpowers/specs/2026-08-15-catalyst-stability-kernel-design.md`

## Global Constraints

- Use only the authorised Sage wallet named `TEST 7`, fingerprint `736588221`, expected key kind `bls`, on Chia mainnet.
- Use `Decimal` for prices and amounts and integer mojos for coin amounts.
- Keep `DRY_RUN=true`, `ENABLE_COIN_PREP=false`, `SNIPER_ENABLED=false`, `DEXIE_AUTO_POST=false`, `DEXIE_POST_ENABLED=false`, and `SPLASH_ENABLED=false` until the bounded live stage.
- Do not test update installation, history/database purges, full reset, credential changes, or external-link launching against the live desktop; cover those paths with the automated suite.
- Stop at the first broken end-to-end boundary, preserve evidence, fix with a regression test, rebuild, and restart this plan from the affected task.
- Finish with zero CATalyst-managed open offers, zero offer locks, all six stability blocker counts at zero, and all TEST 7 balances spendable apart from ordinary network fees.
