## Intended test scope

The candidate is Dexie-first for CAT/XCH offers. Optional Splash is an offer
broadcaster and starts disabled for new installs. Testers can exercise the
startup flow, Sage connection, exact pair selection, Market view, offer
planning, stop/restart, logs, and Debug Bundle. If electing to test mainnet
wallet actions, verify the full CAT asset ID, Sage wallet fingerprint,
balances, pending transactions, existing offers, plan limits, and fee scope
in the app before each action. Use a wallet and amount appropriate for a test.

Report defects through the
[CATalyst issue forms](https://github.com/catalystxch/catalyst-bot/issues/new/choose).
Include the candidate commit, Windows version, a concise reproduction, and a
redacted Debug Bundle when useful. Never upload seed phrases, private keys,
wallet TLS keys, or unredacted personal wallet data.

## Evidence and open limitations

The exact Windows package, isolated installer, Defender scan, primary and
secondary full backend suites, and Chromium suite passed. A packaged
synthetic Sage lifecycle covered create, publish, requote, cancel,
restart/recovery, fill, and remake without duplicate mutation. Separate
synthetic authority-conflict and prepared-input recovery scenarios failed
closed, then reconciled without a wallet mutation. The current primary
original-profile stopped-window and secondary synthetic canary are running;
neither has completed 24 hours.

This candidate still lacks an exact-build active-offer lifecycle against the
original TEST 7 mainnet profile, secondary original-profile live acceptance,
full original-profile native UI traversal, a separate Splash peer's receipt
of identical offer bytes, both completed final-candidate 24-hour audits, and
final review. Those gaps matter when assessing unattended use and real funds.
The complete gate ledger remains in
[release acceptance](v1.4.0-release-acceptance.md).

The public website download path requires a v1.4.0 tag on protected `main`,
a public prerelease, and a signed update manifest. This pinned tester link
does not perform or imply those publication steps.
